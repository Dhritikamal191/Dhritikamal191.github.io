GitHub Repository Live Demo

Project Overview

AI Research Assistant is an advanced Retrieval-Augmented Generation (RAG) system developed to answer questions directly from uploaded PDF documents. Instead of relying solely on a Large Language Model, the application combines semantic vector search, keyword retrieval, reranking, conversation memory and query expansion to generate accurate, context-aware responses with source citations.

Hybrid Search

FAISS vector search combined with BM25 keyword retrieval.

Cross Encoder

Re-ranks retrieved chunks for higher answer accuracy.

Conversation Memory

Supports contextual multi-turn conversations.

Query Expansion

Expands user queries for improved document retrieval.

Response Caching

Reduces repeated LLM calls and improves response speed.

Evaluation

Faithfulness and Answer Relevancy evaluation using RAGAS.
