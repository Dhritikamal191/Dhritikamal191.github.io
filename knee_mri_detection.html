AI Knee Osteoarthritis Detection

An end-to-end computer vision system that predicts knee osteoarthritis severity from X-ray images using an Ordinal ResNet50 model, with Grad-CAM explainability, FastAPI inference, Streamlit deployment and Dockerized production architecture.

View GitHub Live Demo Model

Project Overview

The project transforms a trained deep learning model into a complete deployable AI system. Instead of stopping at model training, the workflow covers inference, explainability, API serving, interactive visualization, monitoring, automated testing and containerization.

The model predicts five ordered osteoarthritis severity levels, from Grade 0 to Grade 4. The ordinal formulation allows the model to preserve the natural ordering between severity levels.

What Changed After the Project

From Model → Application

The trained ResNet50 model was converted into an interactive application capable of accepting new X-ray images and returning an OA severity prediction without requiring users to run training notebooks.

From Prediction → Explanation

Grad-CAM was integrated so predictions are accompanied by visual explanations showing image regions that influenced the model.

From Script → API

FastAPI transformed the inference pipeline into a reusable REST service that can be consumed by applications or other systems.

From Local → Deployable

Docker and Docker Compose package the Streamlit interface and FastAPI backend into reproducible services that can be launched consistently across environments.

From Model Artifact → Verified Model

SHA256 model verification was added to confirm that the model loaded during inference matches the expected Hugging Face model artifact.

From Development → Tested System

Automated tests cover API behavior, model creation, inference outputs, confidence values, probability validity and preprocessing.

Prediction output

Ordinal Prediction

Rather than producing only a single class label, the model generates four ordinal threshold probabilities representing whether the severity exceeds each threshold.

Output Meaning
Grade ≥ 1 Probability that severity reaches Grade 1 or above
Grade ≥ 2 Probability that severity reaches Grade 2 or above
Grade ≥ 3 Probability that severity reaches Grade 3 or above
Grade ≥ 4 Probability that severity reaches Grade 4

ML Engineering

Configuration Management

Model and application parameters are maintained in YAML configuration files rather than being scattered throughout the application code.

Model Version Control

The production model is retrieved from Hugging Face and its SHA256 checksum is recorded during inference.

Monitoring

Monitoring utilities provide prediction metrics, model monitoring and drift detection capabilities.

Automated Testing

Pytest validates API endpoints, model behavior, inference outputs and preprocessing logic.
